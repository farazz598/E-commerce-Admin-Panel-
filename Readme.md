#  Ecommerce Admin Panel (Full Stack)

This is a modern full-stack admin dashboard for managing products and orders, with authentication. Built using:

- **Frontend:** React + Material UI + Axios
- **Backend:** Flask + MySQL + JWT
- **Database:** MySQL

---

Backend Setup:
    cd backend
    venv\Scripts\activate
    pip install Flask flask-mysqldb Flask-JWT-Extended Flask-Cors passlib
    python run.py


Frontend Setup:
    cd frontend
    npm start
